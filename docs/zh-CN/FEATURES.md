## 页面

- **发现**：问候语、搜索入口与主题快捷入口；“继续聆听”大卡展示当前歌曲与进度；下方为最近播放、
  平台快捷入口、最近添加与已下载。
- **搜索**：输入关键词搜索当前平台；平台 chips 可切换 YouTube、SoundCloud、Bandcamp、BiliBili、
  Niconico、PeerTube、media.ccc.de 等；结果分页，每行支持下载与更多操作；粘贴或分享链接可直接解析。
- **曲库**：统计歌曲数、总时长与占用空间；“导入文件夹”递归导入 mp3、m4a、aac、flac、wav、ogg、opus，
  并读取元数据与封面；支持全部／已下载／最近添加／收藏筛选与多选批量操作。
- **歌单**：收藏与自建歌单以马赛克网格展示；详情页支持播放全部、随机播放、排序与移除；也可在加入时
  新建歌单。
- **我的**：品牌头图与统计、主题预览入口、外观设置、下载音质、存储管理、支持平台、开源许可与版本信息。

## 播放

- 迷你播放器位于底部导航上方，显示封面、标题、播放/暂停、下一首与细进度条；点击或上滑打开全屏播放页。
- 全屏播放页包含大封面、标题、艺术家、可拖动进度条，随机、上一首、播放/暂停、下一首、循环，以及
  收藏、加入歌单、下载、队列与睡眠定时。
- 循环模式：顺序、列表循环、单曲循环；随机可与任意模式组合。
- 支持后台播放、媒体通知、锁屏控制与耳机按键；睡眠定时到点停止播放。

## 下载

下载以前台任务运行，离开页面不中断，进度在下载面板展示。有纯音频流时保留原容器与编码，否则用 FFmpeg
提取音轨。文件保存到私有 `files/music/`，封面保存到 `files/artwork/`。

## 存储与备份

导入与下载的文件位于应用私有目录，已从 Android 云备份中排除。**卸载应用会删除这些文件**，重要内容请先备份。

## 外观

8 套预设主题、自定义主色（HSV 取色器与十六进制输入）、浅色／深色／跟随系统／纯黑、Android 12+ 动态取色、
播放页封面取色，所有选择在重启后保留。

## 权限

| 权限 | 用途 |
| --- | --- |
| 网络 | 搜索、播放与下载 |
| 前台服务／媒体播放 | 后台播放与媒体通知 |
| 通知（Android 13+） | 播放控制、下载与导入进度 |
| 文件夹访问（SAF） | 导入本地音乐库 |

应用不会申请整个共享存储的读写权限，导入通过系统选择器与持久化 URI 授权完成。
