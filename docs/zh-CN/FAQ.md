# 常见问题（中文辅助）

> 对应英文文档：[../FAQ.md](../FAQ.md)。两者冲突时以英文为准。

## 通用

**PipeMusic 与 PipePipe／NewPipe 是什么关系？**
PipeMusic 是 PipePipe 的独立音乐分支，PipePipe 又是 NewPipe 的分支。三者没有隶属或背书关系，上游版权
声明与 GPL-3.0 许可证均保留。

**为什么 applicationId 还是 `InfinityLoop1309.NewPipeEnhanced`？**
修改它会破坏现有更新通道，并让已下载的数据对应用不可见。这只是兼容细节，应用显示名是 **PipeMusic**。

**为什么发布的是 debug 包？**
发布包直接用标准调试密钥签名，无需私钥即可安装；功能完全一致，只是签名与 applicationId 后缀不同。需要
固定 applicationId 时可自行签名构建 release 包。

## 播放

**某平台搜不到或播放失败？**
部分平台需要 Cookie、登录、住宅 IP 或人机验证，可用性随网络与地区变化。可换平台或换网络重试。

**播放一会儿就停？**
流地址会过期，应用会自动重新解析一次并恢复位置；若平台持续拒绝，请稍后重试或改为下载后离线播放。

**通知消失了？**
系统电池优化可能杀掉后台服务，请在系统设置中把 PipeMusic 加入电池优化白名单。

**耳机／蓝牙按键无效？**
需要先建立媒体会话：安装后先播放一次，并在 Android 13+ 授予通知权限。

## 下载与导入

**下载失败？**
常见原因是平台未提供可下载的音频流、链接过期或触发限流，可在下载面板重试；仅 HLS 的来源会尝试用 FFmpeg
处理。

**导入的文件消失了？**
文件保存在应用私有目录，卸载应用或在「我的 > 存储」中清理会删除它们，请提前备份。

**大文件夹导入很慢？**
扫描是递归的，复制使用 64KB 缓冲流式进行；请保持应用在前台直到进度完成，或分批导入子目录。

## 外观

**主题重启后重置？**
偏好保存在 DataStore。若被重置，通常是应用数据被清除；重新设置一次即可保持。

**动态取色不可用？**
动态取色要求 Android 12 及以上且启动器支持，否则静默回退到所选预设主题。

## 隐私

**会记录什么日志？**
仅服务 ID、轨道 ID 与错误类型，Tag 为 `MusicPlayer`、`MusicSearch`、`MusicImport`、`MusicDownload`；
不记录 Cookie、带签名的流地址或用户文件路径。

**会上传我的曲库吗？**
不会，曲库、歌单与历史全部保存在设备本地。

## 构建问题

参见 [BUILD.md](BUILD.md)，最常见的是缺少 `local.properties` 与 JVM 低于 Java 25。
